# Python Encrypted Chatroom

A **terminal-based encrypted chatroom** built using Python sockets.
It supports **multi-client messaging, private messages, file sharing with corruption detection, chat history persistence, and admin monitoring**.

This was developed as a **course-end project for Computer Networks**.

---

## 🚀 Features

- **Secure Communication**: All messages and files are encrypted using Fernet (AES).
- **Multi-Client Support**: Handles multiple users simultaneously with threading.
- **Private & Broadcast Messaging**: Support for `/msg` (private) and `/all` (broadcast).
- **Secure File Transfer**: Encrypted file sharing with integrity checks.
- **Admin Dashboard**: The first user becomes Admin and can view all chat history.
- **Persistent History**: Chats are saved to `chat_history.json`.
- **Cross-Platform**: Works on any system with Python 3.

---

## 🛠️ Tech Stack

- **Language:** Python 3
- **Libraries:** `socket`, `threading`, `cryptography`, `os`, `sys`
- **Interface:** Terminal only (no HTML/GUI)


## ⚡ How to Run

### 1. Start the Server

```bash
python server.py
```

### 2. Run Clients (in separate terminals or PCs on the same network)

```bash
python client.py
```

### 3. Enter Username

- First user = `[ADMIN]`
- Others = normal users

## 💬 Commands

### For All Users:

```
/all <message>         → Broadcast to all users
/msg <user> <message>  → Send private message
/file <user> <path>    → Send a file
/list                  → Show active users
/quit                  → Disconnect
/help                  → Show help
```

### For Admin Users Only:

```
/admin_history         → View all chat history (including private messages)
```

## 🔑 Encryption Key Setup

This chatroom uses **Fernet (AES + HMAC)** for encrypting all messages and files.  
The encryption key is stored in `chat_fernet.key`.

### ⚠️ Important Security Note

- The `chat_fernet.key` is **generated by the server** on the first run.
- **Clients need this file** in the same directory to connect.
- **NEVER commit** this key to GitHub (it is ignored by `.gitignore`).
- If you are running clients on different machines, you must **securely copy** `chat_fernet.key` from the server to each client.

## 🌟 Usage Example: Secure Group Chat

Here is how you can set up a secure chat with 3 friends (Alice, Bob, Charlie):

1.  **Alice (Admin)** starts the server:

    ```bash
    python server.py
    # Output: Generated new encryption key: chat_fernet.key
    # Output: Server listening on 0.0.0.0:5000
    ```

2.  **Alice** shares the generated `chat_fernet.key` with Bob and Charlie (via USB, secure email, etc.).

3.  **Alice** connects as Admin:

    ```bash
    python client.py
    # Enter username: alice
    ```

4.  **Bob and Charlie** put `chat_fernet.key` in their project folder and connect:

    ```bash
    python client.py
    # Enter username: bob
    ```

5.  Now everyone can chat securely! All messages on the network are encrypted.

## 📂 File Sharing

- Files are sent in encrypted chunks.
- The receiver stores them in a **downloads/** folder.
- File corruption is checked (`expected size vs received size`).
